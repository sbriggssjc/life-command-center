# Comps blank templates — SINGLE SOURCE OF TRUTH

This folder (`bov-generator/templates/`) is the **single source of truth** for every
blank Briggs comps template. The comps renderer
(`bov-generator/comps_generator.py::populate_comps`) loads these files, and the
conformance validator (`bov-generator/validate_comps_output.py`) mirrors their
canonical column lists. **Edit the template here; never anywhere else.**

## Derived copies — never hand-edit

Copies of these templates that live outside this folder are **DERIVED** and must be
refreshed **from here**, exactly like the canon/render system's surface sync — never
hand-edited, never forked:

- **Project knowledge** uploaded to the Northmarq / Copilot Claude Project (the
  blank templates an agent references when a connector is down).
- Any `Templates/` distribution folder on the shared drive.

If a distributed copy drifts from this folder, the copy is wrong. Fix it by
re-running the sync below, not by editing the copy.

> Note: `assets/work-product-templates/comps/` is a **separate lineage** — the
> Work-Product-Framework restyle-chrome templates generated by
> `scripts/build_lease_comps_template.py`. It is not a distributed copy of these
> renderer templates and is out of scope for this sync.

## Refresh the distributed copies — one command

```bash
python bov-generator/sync_comps_templates.py --dest "/path/to/project-knowledge-or-Templates-folder"
# dry-run (show what would copy, change nothing):
python bov-generator/sync_comps_templates.py --dest "/path/..." --dry-run
```

The script copies the four templates above verbatim into `--dest` (or the
`COMPS_TEMPLATE_DEST` env var). It is one-directional (source → dest) so a
distributed copy can never flow back and become the source.

## Conformance

Every workbook the renderer produces is checked by `validate_comps_output.py`
before delivery (sheet set, canonical headers, formula-protected columns, trimmed
grid + AVG ranges, 0 recalc errors). A non-conforming workbook is an error, not a
delivered file. When you change a template's columns here, update the canonical
lists in `validate_comps_output.py` (the `SPECS` dict) in the same change.
