# `docs/claude-code/prompts/done/` — finished prompts (current convention)

A prompt for Claude Code is drafted in `docs/claude-code/prompts/` and moved here once its work
has merged. Its paired response lives separately in `docs/claude-code/responses/` →
`docs/claude-code/responses/done/` — prompts and responses are **not** filed together here.

For the earlier flat scheme (prompt + response together in one folder), see
`docs/claude-code/done/` — that folder is legacy/historical; do not add new files to it.
