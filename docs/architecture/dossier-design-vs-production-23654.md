2. **Transaction timeline uses the weaker source first.** The correct live `sales_transactions` row has the $3.15M sale, 5.40% stated / 5.78% calculated cap, and 15-year term, but Deal History prefers `property_sale_events`, which returns $3.137M, 5.99%, no firm term.

4. **Operations values conflict depending on loader tier.** CMS/rankings say 33 current patients and 4,283 TTM treatments, while patient history/trend has a future-dated 2026-12-31 row with 131 patients and the property denorm still has the known-bad $104.6M revenue.
5. **The v2 dossier is not wired.** The production button is a v1 client renderer, so location/trade area, BD efforts, market competition, current rent, value basis, document status, and most lease abstraction fields are omitted even when panel loaders have the ingredients.
